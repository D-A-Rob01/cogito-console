# Cogito Console

Cogito Console is a local AI observability and steering prototype. It streams token events over FastAPI websockets, renders the run as an inspectable graph, and lets an operator click an alternative token to rewrite the active path mid-stream.

The backend Python package is `cogito_console`.

## The Rule

No unlabeled fake telemetry.

Every displayed metric is tagged:

- `REAL`: directly returned by a provider/API/runtime/system measurement.
- `DERIVED`: computed from real values with a documented formula.
- `SYNTHETIC`: generated by local demo mode and explicitly labeled as demo-only.

If a provider does not return alternatives, logprobs, or hidden states, Cogito does not silently invent them. Demo overlays are labeled synthetic.

## What Is Real Now

- WebSocket session lifecycle and cancellation timing.
- Runtime token latency and byte length.
- Operator rewrite count.
- SQLite persistence of sessions, runs, packets, evidence, metrics, graph nodes, graph edges, and rewrites.
- Graph/rewrite provenance emitted by the server.

## What Is Synthetic In Demo Mode

- Local demo token logprobs.
- Local demo top alternatives.
- Local demo signal-panel values.
- Prompt-check confidence scores.
- Context mesh weights.

Synthetic values are still useful for exercising the steering machinery, but they are not provider telemetry.

## Run

```powershell
cd outputs\cogito-console
python -m pip install -e .[dev]
python -m uvicorn cogito_console.server:app --reload --host 127.0.0.1 --port 8000
```

Open:

```text
http://127.0.0.1:8000
```

## Configuration

```powershell
$env:COGITO_PROVIDER = "demo"      # demo | openai
$env:COGITO_MODEL = "gpt-4.1-mini"
$env:COGITO_ENABLE_SYNTHETIC_PROBES = "true"
$env:COGITO_PERSIST = "true"
$env:COGITO_DB_PATH = ".\data\cogito.sqlite"
$env:OPENAI_API_KEY = "..."
```

OpenAI mode is scaffolded to fail gracefully without `OPENAI_API_KEY`. When provider logprobs/top alternatives are not returned, the UI shows that absence instead of pretending.

## WebSocket Steering

The browser sends:

```json
{
  "type": "steer",
  "token_id": 7,
  "alternative": { "token": "skeptical ", "logprob": -1.12 }
}
```

The server cancels the active stream, flushes its buffer, splices the `TokenTransactionLog` at `token_id`, normalizes whitespace/open markers, emits a `RewriteEvent`, and resumes from the rewritten history.

## Graph Meaning

- Prompt nodes represent operator input.
- Prompt-check nodes represent pre-generation validation.
- Provider nodes represent the active adapter.
- Token nodes represent accepted path events.
- Alternative nodes represent available branches.
- Rewrite nodes represent operator-selected branch changes.
- Context nodes represent temporary session context that evaporates at completion/clear.

Click any token or alternative to inspect what it means, where values came from, why they matter, caveats, evidence IDs, and raw data in Expert Mode.

## Test

```powershell
python -m pytest -q -p no:cacheprovider --basetemp .pytest-tmp
```

The suite covers metric formulas, synthetic status propagation, OpenAI missing-key behavior, SQLite persistence, graph construction, rewrite provenance, and five concurrent websocket sessions steering at once.

## What Not To Claim

- Do not claim hidden-state access in OpenAI mode.
- Do not treat local demo logprobs as model probabilities.
- Do not compare synthetic demo alternatives against provider alternatives as equivalent evidence.
- Do not hide missing provider data. Missing data is a finding.
